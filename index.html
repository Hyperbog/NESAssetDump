NES Asset Ripper — Godot Edition

Offline desktop app for 8×8 NES graphics extraction and Godot-ready assets. Load ROMs or ZIP collections; no emulator or account required.

1. Game library

Drag files here to add them to your library. ZIP files are decompressed locally, one selected game at a time.
Open a ROM or a ZIP containing .nes games to begin.

2. Graphics

CHR-ROM gives exact tiles. For CHR-RAM games, a raw PRG scan is exploratory and may not reveal compressed assets.

3. Palette variants

A ROM tile does not encode its color palette or sprite identity.

16-byte or 32-byte NES palette indices, or 192-byte 64×RGB master palette.
0 manually assigned tiles
PRG palette candidates are unverified. Raw .pal export is available only for a selected 16/32-byte palette set. All exports retain provenance; PNG/CSV RGB values are approximate reference colors.

5. Export for Godot

PNGs are native-resolution with 8×8 tile alignment, no spacing or filtering. CHR-ROM raw extraction is exact; PRG scans are not confirmed game graphics. NES RGB colors are a reference approximation.

Godot 4 setup

Set texture filtering to Nearest. Use TileSetAtlasSource with texture_region_size = (8, 8), margins = (0, 0), and separation = (0, 0). For Sprite2D, enable regions; for AnimatedSprite2D, import frames from a sprite sheet.

Palette colors depend on game runtime state. Accurate sprite-palette association cannot be determined from CHR-ROM alone, although imported palette sets and manual associations can be preserved.
